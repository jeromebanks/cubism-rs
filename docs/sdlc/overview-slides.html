Every slice earns its merge

Two review layers sit on top of deterministic checks.

1 · ClaimA stable `issue/N` branch prevents two sessions from owning the same work.
2 · BuildThe agent implements in an isolated worktree and runs focused plus repository checks.
3 · AdviseClaude requests advisor review of the plan and diff when that facility is available.
4 · ReviewA fresh Codex session reviews the committed PR—not the implementer's description.
5 · GateCI, issue type, merge state, and an exact-SHA review receipt must all pass.
Passing slices merge without routine human review.

Trust is encoded

The scripts prevent the most tempting optimistic shortcuts.

One issue, one claimRemote branch creation acts as a distributed lock.
One PR, one sliceAmbiguous closing references block the merge.
Review follows codeAny new commit invalidates the prior receipt.
Missing means blockedNo agent guesses about CI, mergeability, or approval.
Humans own gatesApproval and feedback are recorded on the epic.
GitHub owns stateHTML is a readable snapshot, never a second tracker.
Autonomy is safe because uncertainty fails closed.
